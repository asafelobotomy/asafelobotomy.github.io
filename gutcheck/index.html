GutCheck

A health check across every GitHub project in a folder.

Download v0.27.1Source on GitHubSupport

What it does

GutCheck scans a folder of repos and grades each one: CI, pull requests, branches, docs, Actions security, dependencies, releases, settings, clutter, tests and AI agent setup. It runs on your existing gh and git login, never handles tokens itself, and also works as a command line and an MCP server so coding agents can use the same checks.

Features

One scan, every repoCI, PRs, branches, docs, security, dependencies and releases, graded A to D.
Fixes you see firstEvery change shows the exact commands before it runs, and only those run.
Actions securityScript injection, unpinned actions and loose permissions, read as text.
Your own rulesIgnore a finding with a reason, or set a baseline every repo should meet.
AI agent setupChecks CLAUDE.md and AGENTS.md size, drift and risky permission rules.
Local and privateNo account, no server, no telemetry. GitHub data comes through gh.

Install

AppImage

chmod +x GutCheck-*.AppImage
./GutCheck-*.AppImage

From source

npm install
npm start

Needs gh and git on your PATH, with gh auth login done. Each release ships SHA256SUMS.txt.
