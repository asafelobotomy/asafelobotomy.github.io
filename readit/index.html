readit

Profile-first extension for New Reddit: for readers, creators and moderators.

Download v0.2.4Source on GitHubSupport

What it does

readit reshapes New Reddit around who you are rather than restoring Old Reddit. Pick a profile and it sets layout, density and tools to match. A clean-room build, inspired by RedditEnhancer and Moderator Toolbox workflows.

Install

Chrome

npm install && npm run build
# chrome://extensions → Developer mode → Load unpacked → dist/chrome-mv3

Firefox

npm run build:firefox
# about:debugging → Load Temporary Add-on → dist/firefox-mv3/manifest.json

Store listings would remove the build step for most people; see suggestions below.
