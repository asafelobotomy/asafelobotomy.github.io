XZram

Cross-distro swap management: zram, swap files, partitions and sysctl tuning.

Download v0.4.3Source on GitHubSupport

What it does

XZram is CLI-first. Diagnostics run without root; changes are staged and applied atomically, with a snapshot before every apply so you can roll back. A Qt6 GUI and an optional D-Bus daemon sit on top.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Read-only diagnosticsstatus, detect and doctor, no root needed.
Staged applyChanges stage to pending.json; apply runs them atomically.
zramConfigures systemd-zram-generator and migrates from zram-tools.
Swap filesCreate, resize, remove; enforces nodatacow on btrfs.
Sysctl tuningSwappiness, watermark and page-cluster.
SnapshotsAutomatic backup before every apply, versioned restore.
