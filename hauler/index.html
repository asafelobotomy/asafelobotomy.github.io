hauler

Fast, resumable downloads over parallel connections. Linux first.

Download v0.1.2Source on GitHubSupport

What it does

hauler splits each file across many connections and rebalances them as they finish: when a connection runs out of work, it takes the upper half of whichever segment has the most left. Progress is synced every two seconds, so a crash or reboot resumes where it stopped.

Features

Dynamic splittingIdle connections steal half of the largest remaining segment.
Crash-safe resumeOne preallocated .part file plus an atomic progress file.
Safe resumeIf-Range on every request; a changed file restarts instead of mixing versions.
Live speed limitsPer-download and global token buckets, adjustable while running.
Daemon & queuehaulerd with JSON-RPC over a user socket, SQLite queue, priorities.
Plays nice with LinuxPlasma job tracker, logind sleep inhibitor, NetworkManager metered pause.

Install

User install

scripts/install-user.sh

Queue a download

hauler add -x 16 --limit 2M https://example.com/big.iso
hauler watch

One-off

hauler get -x 16 --checksum sha256:<hex> https://example.com/big.iso

The desktop app needs Qt 6, Kirigami, KItemModels and qqc2-desktop-style. On Arch and Manjaro these come with Plasma.
