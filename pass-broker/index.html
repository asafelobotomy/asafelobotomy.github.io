Pass Broker

Let AI assistants sign in with your Proton Pass logins without ever seeing them.

Download v0.3.1Source on GitHubSupport

What it does

Pass Broker runs on your PC as a remote MCP server. Assistants such as Claude drive a locked-down browser through redacted tools and only ever get handles, masked snapshots and blacked-out screenshots. Every secret stays on your PC, and every use needs your approval on your desktop.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Secrets never leavePasswords, 2FA codes and your Proton Pass token stay on your PC.
Approve every useA desktop prompt for each sign-in, file unlock or device action.
Locked-down browserSandboxed Chromium that only shows web pages and refuses permissions.
Setup wizardSix steps from requirements to connecting assistants, each locked once confirmed.
Control centerStart and stop the broker, watch each bot's masked tab, revoke or stop it all.
Beyond sign-insUnlock files, email codes via Proton Mail Bridge, home-device actions over ssh.

Install

AppImage

chmod +x Pass_Broker-x86_64.AppImage
./Pass_Broker-x86_64.AppImage

From source

uv sync
cargo build --release --manifest-path wizard/Cargo.toml
wizard/target/release/passbroker-wizard

Needs the Proton Pass CLI and a desktop that shows notifications. The AppImage runs on glibc 2.35 or newer and downloads Chromium on first run.
