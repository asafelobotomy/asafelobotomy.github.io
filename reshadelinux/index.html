ReShadeLinux

Install the official ReShade runtime for Wine and Proton games.

Download v1.4.1Source on GitHubSupport

What it does

ReShadeLinux finds your Steam games, picks the right ReShade hook DLL by reading each executable's imports, and keeps per-game shader choices. ReShade itself is by crosire and its contributors; this project continues kevinlekiller's reshade-steam-proton installer flow.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Steam detectionScans every Steam library and reads appinfo.vdf for the real launch executable.
DLL selectionPE import analysis picks dxgi, d3d9, opengl32, ddraw or dinput8.
Per-game stateRemembers DLL, architecture, path and shaders per game.
GUI or CLIyad dialogs, falling back to whiptail, dialog, then plain prompts.

Install

AppImage

chmod +x reshadelinux-*-x86_64.AppImage
./reshadelinux-*-x86_64.AppImage

From source

git clone https://github.com/asafelobotomy/reshadelinux.git
cd reshadelinux
./reshadelinux.sh

Needs 7z, git, curl, file and python3 on the host. Install yad for the graphical flow.
