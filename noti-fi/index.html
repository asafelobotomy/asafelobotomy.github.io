noti-fi

A notification daemon for KDE Plasma on Wayland, with rules, groups and a control panel.

Download v0.18.0Source on GitHubSupport

What it does

noti-fi (notification fidelity) replaces Plasma's built-in notification service with notifd, built on Quickshell. Rules route each popup into a named group with its own corner of the screen, and the notify command installs it, switches Plasma over and back, and gives you Do Not Disturb, muting, history and a hotkey.

Features

Groups & rulesRoute popups by app, site, urgency or text, each group in its own corner.
Safe takeovernotify takeover --dry-run shows every change; notify restore undoes it.
Screen-share awareHides notification text while the screen is shared or captured.
File-job progressDolphin copies, moves and extracts show as popups with live progress.
Control panelKirigami app for history, appearance, focus modes, groups and rules.
Self-updatingnotify upgrade checks the release checksum before replacing anything.

Install

From a release

tar xzf noti-fi-*-linux.tar.gz && cd noti-fi-*-linux
./install.sh
notify takeover --dry-run
notify takeover --now

Arch (build)

cd packaging && makepkg -si

Update

notify upgrade --apply

Needs quickshell, qt6-declarative, kirigami and qqc2-desktop-style at run time. qt6-multimedia is optional.
