Buckler

Debloat and relaunch your NVIDIA SHIELD TV Pro, safely.

Download v0.23.0Source on GitHubSupport

What it does

Buckler is an ADB command-line tool and a custom HOME launcher for the SHIELD TV Pro. Every change is journaled and reversible, OTA drift is detected, and the box is never left without a home screen. It keeps NVIDIA AI upscaling, Play and Chromecast working.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Probe & auditIdentity, HOME owner, package state, AI upscaling health.
ProfilesJournaled disable-user profiles: privacy-core, speech, minimal, extras.
buckler-homeA clean launcher, installed and handed HOME only after it verifies.
After OTAscheck --fix re-applies what an update turned back on.
TidyFind unused apps, clear caches, install open icon packs.

Install

On the TV

# See docs/install.md: install with Downloader on the TV,
# or from a computer over ADB

Typical flow

buckler probe
buckler apply --profile privacy-core
buckler launcher install
buckler launcher handover
