oysterAV

One calm GUI over ClamAV, rkhunter, Lynis and friends.

Download v0.2.3Source on GitHubSupport

What it does

oysterAV is a security orchestrator, not another engine. oyst-cli owns every security action and the GTK4 / libadwaita app is a thin client on top, so the CLI and GUI never disagree. Privileged multi-step flows ask for admin once per action.

Features

Orchestrator, not engineWraps ClamAV, rkhunter, Lynis and more instead of reimplementing them.
CLI owns securityoyst-cli is the source of truth. The GUI only talks to it.
Full or Lite runtimeVendored tools under XDG, or host packages only.
One prompt per actionPrivilege Concert batches multi-step admin work behind one auth.
ShieldFirewall, fail2ban and ban management.
Reports & quarantineHistory, export, resolve; vault with restore and delete.

Install

CLI

uv sync --extra all
uv run oyst-cli setup run --confirm --json
uv run oyst-cli scan ~/Downloads --json

GUI

uv sync --extra gui --extra dev
uv run oysterav

Needs Python 3.12+ and uv. The GUI also needs system GTK4 and libadwaita. First setup can take a few minutes while signatures download.
