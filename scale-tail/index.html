scale_tail

A system-tray control centre for the Tailscale CLI.

Download v0.5.1Source on GitHubSupport

What it does

scale_tail sits in your tray and drives the tailscale command for you: connect and disconnect, pick an exit node, browse peers, send files with Taildrop and switch accounts. It shows up as a StatusNotifierItem, so it works on KDE and on GNOME with AppIndicator.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Connect in a clickConnect, disconnect, auto-connect on launch and start on login.
Exit nodesPick one, clear it, or use the suggested node.
PeersCopy IPs and DNS names, ping, and send files with Taildrop.
TogglesDNS, subnet routes, LAN access, shields up, Tailscale SSH, advertise exit node.
AccountsSwitch accounts, with a login prompt when Tailscale needs auth.
UpdatesRelease checker plus zsync update info for Gear Lever and AppImageUpdate.

Install

AppImage

chmod +x scale_tail-*.AppImage
./scale_tail-*.AppImage

From source

cargo run --release

No root needed

sudo tailscale set --operator=$USER

Needs tailscale, libnotify, xdg-utils, wl-clipboard or xclip, and zenity for sending files.
