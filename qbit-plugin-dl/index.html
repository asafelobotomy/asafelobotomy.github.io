qbit Plugin Manager

Pick and install qBittorrent search plugins from allowlisted catalogs.

Download v0.2.1Source on GitHubSupport

What it does

Merges the unofficial wiki list, the official nova3 engines and LightDestory's catalog, filters by category and installs straight into qBittorrent's engines folder. Discouraged entries stay unchecked and every plugin gets a static safety check first.

Screenshots

Screenshots coming soon. Until then, the README on GitHub has the full tour.

Features

Multi-sourceWiki, official nova3 and LightDestory, cached for 6 hours.
Category filtersAnime, books, games, movies, music, software, TV and more.
Safer defaultsStatic review, optional ClamAV scan, discouraged entries unchecked.
Finds qBittorrentFlatpak and native engine folders detected automatically.
