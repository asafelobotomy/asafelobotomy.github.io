emobie

A compact emoji palette for content creators. Summon, search, copy, done.

Download v0.8.2Source on GitHubSupport

What it does

emobie puts the full Unicode emoji set behind a global hotkey and a tray icon. Favourites, recents, text macros and as-you-type expansion make it a small writing tool as much as a picker.

Screenshots

Features

Full catalogEvery Unicode emoji via emojibase; search by name, tag or shortcode.
Summon anywhereGlobal hotkey (Ctrl+Shift+Space) and system tray.
MacrosTrigger → expansion cards, per-macro hotkeys, YAML import/export.
Expand as you typeOpt-in: type a trigger anywhere to replace it.
Pin on topAlways-on-top on X11, Plasma Wayland and GNOME Wayland.
Self-updatingOptional check that installs the matching release asset.

Install

Flatpak

flatpak install --user emobie-*-x86_64.flatpak
flatpak run io.github.asafelobotomy.emobie

.deb

sudo apt install ./emobie_*_amd64.deb

.rpm

sudo dnf install ./emobie-*-1.x86_64.rpm

AppImage

chmod +x emobie_*.AppImage && ./emobie_*.AppImage
